# 03 — Adaptive Agenda
## Purpose
Describe the UI/UX strategy that shows only the three critical tasks (HOJE) and a secondary list (DEPOIS DISSO) while keeping the rest of the backlog hidden.
*Draft content goes here.*
## Design Goals
- Minimalist daily view.
- Context‑aware expansion based on energy level.
- Seamless transition from morning to evening dashboards.
## Architecture
- **Data Source**: `00 Sistema/Daily Dashboard.md` generated by the Executive Assistant.
- **Renderer**: Obsidian Custom CSS snippet (`adaptive_agenda.css`) that uses `:has()` selectors to hide non‑top‑3 entries.
- **Interaction**: User can click a **+** button to reveal the next item if energy permits.
## Implementation Steps
1. Create CSS snippet `adaptive_agenda.css` in `.obsidian/snippets/`.
2. Add a Toggle block in the dashboard:

```markdown
```ad‑agenda
- [[Task 1]]
- [[Task 2]]
- [[Task 3]]
```
```
3. Use a small JS plugin (optional) to auto‑populate the block each morning.
