# tales-of-talles
TALES OF TALLES · IDENTITY OS is a single-file HTML PWA for MMA performance tracking. Sci-fi glassmorphism UI, AI coaches (Sanji, Ilia, Cariani, Muzy), striking progression, muscle heatmap, readiness scoring, event-driven architecture, offline persistence, and elite athlete development focused on a 1.94m welterweight moving from 77kg to 84kg.
