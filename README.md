# tales-of-talles# 🥊 TALES OF TALLES · IDENTITY OS

**TALES OF TALLES · IDENTITY OS** is a futuristic, offline-first Personal Evolution Operating System built for MMA athletes.

Designed as a single-file HTML PWA, it combines training intelligence, striking progression, body composition tracking, recovery monitoring, and AI coaching inside a cinematic sci-fi interface.

Built specifically around the development of a 1.94m welterweight athlete progressing from **77kg → 84kg**, the system transforms physical evolution into a living identity framework.

---

## ⚡ Core Philosophy

This is not a fitness app.

TALES OF TALLES is an **Identity OS** designed to simulate, measure, and accelerate long-term athletic development through event-driven progression systems.

The experience combines:

* UFC-style striking progression
* Strength & conditioning tracking
* Recovery intelligence
* Muscle activation analytics
* Readiness monitoring
* AI coaching agents
* Long-term athlete evolution

## 🏗 Architecture

TALES OF TALLES follows a strict event-driven architecture.

### Non-Negotiable Rules

* Single-file HTML/CSS/JS
* Pure deterministic reducer
* Immutable event history
* Replay-safe state transitions
* Backward-compatible updates only
* No regressions between versions

### Event Types

```text
COMPLETE_GYM_EXERCISE
COMPLETE_BOXING_DRILL
ADD_BODY_SCAN
DECAY
```

### Persistence

| Layer          | Purpose                |
| -------------- | ---------------------- |
| IndexedDB      | Events & Snapshots     |
| localStorage   | UI/Profile Preferences |
| Service Worker | Offline Support        |
